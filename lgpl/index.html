Heicly open-source components

Source code offer for Heicly 1.0 (Microsoft Store app "Heicly: HEIC to JPG Converter & Viewer").

Heicly decodes HEIC/HEIF photos with libheif and libde265, which are licensed under the GNU Lesser General Public License v3.0 (LGPL-3.0), and writes WebP with libwebp (BSD-3-Clause). These libraries ship as separate DLLs that Heicly loads at run time. Below are the exact sources of the versions shipped in this release and the script used to build them, with all build options.

The build script pins every download (sources and the llvm-mingw / CMake / Ninja toolchain) by version and SHA-256 and builds x64 and ARM64 DLLs. libheif is built with only the libde265 HEVC decoder; no encoders are included.

Using your own libheif

You may modify these libraries and use your own build with Heicly: in the app open Settings and about (gear button), go to Your own libheif, tick Use my own libheif from this folder and choose the folder that contains your libheif.dll and the DLLs it needs. Heicly uses it from the next start. Reverse engineering Heicly to debug such modifications is permitted.
